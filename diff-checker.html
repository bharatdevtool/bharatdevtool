Everything you need to know about the free Diff Checker

A diff checker (text comparison tool) takes two pieces of text and computes the differences between them line by line. It highlights lines that were added, removed, or changed — using a green background for additions and red for deletions. This tool uses an LCS-based (Longest Common Subsequence) diff algorithm to find the minimal set of edits, exactly like the git diff command does.

Your data is completely safe. All comparison happens entirely in your browser using JavaScript — no text is ever sent to our servers or any third party. You can safely compare passwords, source code, confidential documents, or any sensitive content.

The result shows all differences: green lines are additions, red lines are deletions. Lines that are the same in both texts appear without highlighting. You can also enable "Inline character diff" to see exactly which characters changed within a line.
