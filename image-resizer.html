Frequently Asked Questions

Everything you need to know about the free image resizer

An image resizer changes the pixel dimensions (width and height) of an image. You can resize to exact pixel sizes, scale by percentage, or use social-media presets. Resizing reduces file size for web use, meets platform upload requirements, or prepares images for printing.

This tool supports all common image formats as input: JPG/JPEG, PNG, WebP, GIF, BMP, and SVG. You can download the resized result as JPG, PNG, or WebP — just select your preferred format before resizing.

Completely free, and your images never leave your device. All resizing happens entirely inside your browser using the Canvas API. Your photos are 100% private — no data is sent to any server.

Click the chain-link button between the Width and Height fields. When the lock is active (blue), changing one dimension automatically calculates the other to maintain the original proportions. Unlock it to set width and height independently.

There is no strict limit — it depends on your device's available memory. Most devices handle images up to 20–30 MB with ease. Very large images (50 MB+) may run slowly on older hardware. For best results, images under 10 MB are recommended.
