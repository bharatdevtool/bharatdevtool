Regex Syntax Help

Character Classes

. - Any character except newline
\d - Any digit (0-9)
\w - Word character (letter, digit, underscore)
\s - Whitespace character
[abc] - Any character in brackets
[^abc] - Any character NOT in brackets

Quantifiers

* - Zero or more
+ - One or more
? - Zero or one
{n} - Exactly n times
{n,} - n or more times
{n,m} - Between n and m times

Anchors

^ - Start of string
$ - End of string
\b - Word boundary

Groups

(abc) - Capturing group
(?:abc) - Non-capturing group
(?<name>abc) - Named group

Lookahead/Lookbehind

(?=abc) - Positive lookahead
(?!abc) - Negative lookahead
(?<=abc) - Positive lookbehind
(?<!abc) - Negative lookbehind

Frequently Asked Questions

Everything you need to know about Regex Tester

A regex tester is a tool that allows you to test regular expressions against sample text in real-time. It highlights matches, shows match groups, and provides detailed information about each match including position, length, and captured groups. This tool supports multiple regex flavors including JavaScript, Python, Golang, Java, and PCRE.

The tool supports JavaScript (full execution), Python, Golang, Java, and PCRE. While JavaScript regex can be executed directly in the browser, other flavors are validated for syntax correctness. For full execution of non-JavaScript flavors, backend processing would be required.

Match groups are created using parentheses in your regex pattern. For example, (\d{3})-(\d{3})-(\d{4}) creates three groups for a phone number. The tool will highlight each group with different colors and show their positions in the match details section.

Catastrophic backtracking occurs when a regex pattern causes exponential time complexity, making the regex extremely slow or causing the browser to freeze. The tool detects potential backtracking patterns and warns you about them. Common causes include nested quantifiers and complex alternations.
