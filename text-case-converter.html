Everything you need to know about the Text Case Converter

A Text Case Converter is a free online tool that transforms text between different letter-case formats — such as UPPERCASE, lowercase, Title Case, Sentence case, camelCase, PascalCase, snake_case, kebab-case, and CONSTANT_CASE. It's useful for developers, writers, and anyone who needs to quickly reformat text without manually retyping it.

This tool supports twelve case formats:

  • UPPERCASE — all letters capitalised (HELLO WORLD)
  • lowercase — all letters small (hello world)
  • Title Case — first letter of each word capitalised (Hello World)
  • Sentence case — first letter of each sentence capitalised (Hello world.)
  • camelCase — no spaces, first word lower, subsequent words capitalised (helloWorld)
  • PascalCase — no spaces, every word capitalised (HelloWorld)
  • snake_case — words joined with underscores (hello_world)
  • kebab-case — words joined with hyphens (hello-world)
  • CONSTANT_CASE — all caps with underscores (HELLO_WORLD)
  • aLtErNaTiNg CaSe — alternating upper/lower characters
  • iNVERT cASE — upper becomes lower and vice versa
  • url-slug — URL-safe lowercase slug (hello-world-123)

Yes — your data is completely safe. All text conversion happens entirely in your browser using JavaScript. Your text is never sent to any server, stored, or shared with anyone. You can even use this tool offline once the page has loaded.

In camelCase, the first word is all lowercase and each subsequent word starts with a capital letter — e.g., myVariableName. In PascalCase (also called UpperCamelCase), every word including the first starts with a capital letter — e.g., MyVariableName.

camelCase is standard for variable and function names in JavaScript, Java, and TypeScript. PascalCase is used for class and component names in most object-oriented languages and frameworks like React.

snake_case (words joined by underscores, e.g., my_variable_name) is widely used in Python variable names, database column names, and file names on Linux systems.

kebab-case (words joined by hyphens, e.g., my-variable-name) is standard for CSS class names, HTML attributes, URL slugs, and CLI flags.

CONSTANT_CASE (ALL_CAPS_WITH_UNDERSCORES) is the convention for named constants and environment variables in most languages.
