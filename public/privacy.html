Privacy Policy

Last updated: 10 November 2026

The short version

  • Every tool on Bharat Dev Tools runs inside your browser. What you paste, type or upload (JSON, text, images, PDFs, tokens, cURL commands, QR codes) is processed on your device and is never sent to our servers. We do not have servers that could receive it.
  • No account, no sign-up, no ads.
  • We use anonymous usage statistics (Google Analytics) and error reports (Sentry) to keep the site working. Neither ever contains what you put into a tool.

1. Your data stays on your device

  • Formatting, converting, compressing, hashing, encoding and decoding all happen locally with JavaScript and browser APIs.
  • Some tools remember your last settings or recent items in your browser’s local storage (for example recent deep links or URL encoder history). This stays on your device; you can clear it with the tool’s Clear button or by clearing site data in your browser. Base64 history is kept only until you close the tab.
  • Share links put the data after the # in the link (for example #json=). Browsers never send that part to any server, and our pages remove it from the address bar before analytics loads.
  • The cURL Tester sends the request you build directly from your browser to the API you choose. It does not pass through us.

2. Anonymous usage statistics (Google Analytics 4)

We count page views and which buttons are used (for example “format clicked”, “3 files compressed”, input length) so we know which tools to improve.

  • Events carry fixed labels and counts only: never your input, file names, URLs you enter, or error text.
  • Page addresses are sent without the query string or # part.
  • IP addresses are anonymized. Analytics is off on localhost.
  • To opt out, block cookies for this site or install the Google Analytics Opt-out Add-on.

3. Error reports (Sentry)

When something breaks, Sentry receives a technical report (browser, page, which operation failed, stack trace) so we can fix it. Before a report leaves your browser we remove error messages (they can quote your input), extra data, network and console logs, and the query string from the page address.

4. Cookies and local storage

  • bdt_visited, bdt_last_tool: remember that you have visited and which tool you used last, to show “continue where you left off”.
  • bdt_query_bar: remembers whether you opened the JSON Formatter’s query bar.
  • Tool preferences (theme, font size, indent, options) in local storage.
  • Google Analytics cookies (_ga, _ga_*) for anonymous visit counting.
  • No advertising or profiling cookies.

5. Third-party files we load

Pages load code and images from these services. They receive your IP address and browser details like any website you visit, but never your tool input:

  • Google Tag Manager / Google Analytics (statistics)
  • Sentry (js-de.sentry-cdn.com, error reports, EU region)
  • cdn.tailwindcss.com, cdnjs.cloudflare.com, cdn.jsdelivr.net, unpkg.com (open-source libraries, for example the PDF, ZIP and QR libraries)
  • ImageKit (ik.imagekit.io, our logo and images)

6. Your rights (India DPDP Act 2023 and GDPR)

We do not hold personal data about you that we could look up, correct or delete: we have no accounts and do not receive your tool input. For analytics data held by Google, use the opt-out above. For any privacy question or request, write to feedback@bharatdevtool.com.

7. Changes to this policy

If our practices change we will update this page and its “Last updated” date.
