Frequently Asked Questions

        

          

            
            

              
In Linux crontab, GitHub Actions and Kubernetes it is 0 9 * * 1-5. AWS EventBridge uses cron(0 9 ? * MON-FRI *), Spring uses 0 0 9 * * MON-FRI, Quartz uses 0 0 9 ? * MON-FRI and Azure Functions uses 0 0 9 * * 1-5.

            

          


          

            
            

              
Cron itself has no time zone: it runs in the time zone of whatever reads it. GitHub Actions and AWS EventBridge rules use UTC, so check the next runs in IST and UTC with the checker on this page before you rely on it.

            

          


          

            
            

              
In cron(0 9 ? * MON-FRI *), the ? means "no specific value". AWS EventBridge and Quartz need ? in either the day-of-month or the day-of-week field, while Linux cron uses * in both.

            

          


          

            
            

              
Those formats start with a seconds field. 0 0 9 * * MON-FRI in Spring means second 0 of the same schedule as 0 9 * * 1-5 in Linux cron.
