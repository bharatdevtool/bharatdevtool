Frequently Asked Questions

        
Everything you need to know about the Favicon Generator

        


          

            
            

              
A favicon is the small icon displayed in browser tabs, bookmarks, and address bars that represents your website. Modern websites need multiple sizes:

              
    
                
  • 16×16 — Browser tab (small)
    • 
                
  • 32×32 — Browser tab (standard), Windows taskbar
    • 
                
  • 48×48 — Windows shortcut icon
    • 
                
  • 64×64 — High-DPI tabs
    • 
                
  • 128×128 — Chrome Web Store, macOS
    • 
                
  • 180×180 — Apple Touch Icon (iOS home screen)
    • 
                
  • 192×192 — Android home screen (PWA)
    • 
                
  • 512×512 — PWA splash screen
    • 
              

              
This generator creates all these sizes automatically from a single source image or text.

            

          


          

            
            

              
After downloading your favicons, upload them to your website (typically the root or /assets/img/), then add these tags inside the <head> of every HTML page:

              
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
<link rel="icon" type="image/png" sizes="16x16" href="/favicon-16x16.png">
<link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png">

              
The generated HTML snippet at the bottom of this tool gives you the exact code to copy-paste.
